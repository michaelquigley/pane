explore a small, visible project arrival aid: repo path, bootstrap pointers, active artifact, and deliberately selected recent project memory. clarify what is merely shown to the reader versus supplied to the model, and how selection relates to a conversation. prefer pointers and selective reads over automatic context dumps. project membership is context, not write authority; do not add automatic idea extraction, unattended capture, or a mandatory workflow mode.

## why

conversation and durable project context should be available together without making arrival heavier or turning every exchange into a capture workflow. pane already has a system-prompt editor, but its custom prompt is a browser-wide preference rather than a per-project context record. trial existing guidance before assuming another prompt surface is needed.
