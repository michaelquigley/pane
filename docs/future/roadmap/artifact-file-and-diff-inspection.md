explore a lightweight way to inspect an artifact and its changes alongside the conversation that produced it. start with opening the actual file or a useful diff, not an editor or automatic review workflow. establish where the bytes and comparison baseline come from, how a file becomes in scope, and how the view distinguishes current file contents from an assistant's summary or an older read. inspection must not imply permission to write.

## why

an assistant's summary is not a substitute for inspecting the actual file during revisions. the value is seeing what landed, not adding another artifact-capture system. choose the smallest useful surface after checking whether links or an external viewer suffice.
